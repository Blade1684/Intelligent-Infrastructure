Server Monitoring
Detailed metrics for each application server. History window: ~200 samples (≈200 s since monitor start).
CPU Utilisation ?Percentage of CPU time used by the container. Calculated from Docker cgroup stats. Can briefly exceed 100% on multi-core hosts due to normalisation. Anomaly detection uses Isolation Forest + Z-score — no fixed upper threshold.
Memory Usage (MB) ?Container RSS memory in megabytes. No memory limit is exposed by the API; bars show absolute MB values. Anomaly detection uses statistical deviation — no fixed threshold displayed.
Response Latency (ms) ?Time in milliseconds for the monitor's HTTP health probe to receive a 200 response. Null values shown as gaps. Detection triggers after 3 consecutive readings above 500 ms. Threshold: 500 ms × 3
Disk Utilisation ?Percentage of the container root filesystem used (from df -m /). Shares host filesystem in this Docker configuration. Detection triggers above 85%. Threshold: 85%
